Algorithms Used in This System

Legacy Array (Linear Search)

O(n) Sequential Scan

Checks each IP entry one-by-one. Simple but slow as the list grows.

Real-World Use: Small ACLs, low-volume IoT allowlists, or temporary filters.

String Trie

O(L) String Prefix Walk

Traverses nodes per character. Efficient for prefix matching but memory heavy.

Real-World Use: DNS auto-complete, URL routing, and prefix-based filtering.

Binary Trie

O(32) Bitwise Traversal

Walks one bit at a time through a binary tree of IPs.

Real-World Use: Router lookups, IP routing tables, and firewall rule trees.

Stride-4 Trie

O(8) Stride-Based Traversal

Moves 4 bits per step to reduce lookup depth.

Real-World Use: High-speed routers, TCAM-like software indices, CEF-inspired routing.

DHIF-Cuckoo (Dual-Hash Integer-Fold)

O(1) Dual-Hash Cuckoo Lookup

Each IP has two deterministic positions. Lookups check two slots only.

Real-World Use: Modern firewalls, DDoS mitigation pipelines, and fast access control.
