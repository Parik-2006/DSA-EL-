Unified Cuckoo Hash Table

The Unified Cuckoo Hash Map acts as the high-speed central nervous system of the firewall, consolidating all security rules into a singular, deterministic memory structure. By utilizing the Dual-Hash Integer-Fold (DHIF) engine, the system eliminates fragmented lookup lists and replaces them with two synchronized tables (table1 and table2) where every known IP friend or foe is mapped to a specific memory slot for instant O(1) verification. Each entry contains an optimized 32-bit integer key and a status code that dictates the firewall's action in a single clock cycle.

  • Authorized IPs: 50 hardcoded IPs (Class A-E), stored with status 1 (AUTHORIZED). Packets matching these entries are forwarded instantly with zero additional latency.
  • Blocked IPs: 25 reputation-based IPs loaded from blocked_ips.txt, stored with status 0 (BLOCKED). These packets are dropped at the ingress point.
  • DoS Attack IPs: 25 dedicated simulation IPs, stored with status 2 (DOS_ATTACK). Identification triggers an immediate packet drop and a high-priority red alert on the dashboard.

Why This Is Real Protection

  • Speed: The same O(1) time for authorized or blocked lookups.
  • Accuracy: Integer-only comparison means no false positives.
  • Efficiency: One lookup decides if traffic is safe, malicious, or DoS-related.

Unlisted IPs

If an IP is not found in either cuckoo table, the lookup returns Not Found. In a secure firewall, the default action is to block or drop the traffic so only known-good users get through.

If not found: DROP (default deny)
