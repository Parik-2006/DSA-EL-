Getting Started

Prerequisites

  • Python 3.8 or higher
  • GCC compiler (for backend compilation)
  • Flask framework
  • Modern web browser (Chrome, Firefox, Edge)

Installation Steps

  1. Clone the Repository git clone https://github.com/YOUR_USERNAME/DSA-EL-.git
    cd DSA-EL-
  2. Install Python Dependencies pip install -r requirements.txt
  3. Compile the Backend (Optional) gcc backend.c -o backend.exe
    Note: The C backend provides additional performance optimizations for the DHIF algorithm.
  4. Run the Application python app.py
  5. Access the Dashboard

    Open your browser and navigate to: http://localhost:5000

Quick Start Script

You can also use the provided startup script:

bash start.sh

Algorithm Details: DHIF (Dynamic Hash-Indexed Filter)

Overview

DHIF is our proprietary IP filtering algorithm designed for ultra-fast IP validation in network security systems. It combines hash-based indexing with stride optimization to achieve sub-millisecond lookup times.

Algorithm Comparison

Algorithm Time Complexity Space Complexity Avg. Search Time Best For
Linear Search O(n) O(1) 50-60ms Small datasets
String Matching O(n*m) O(1) 30-35ms Pattern matching
Binary Search O(log n) O(1) 5-6ms Sorted datasets
Stride Search O(n/k) O(1) 1.5-2ms Medium datasets with optimization
DHIF (Ours) O(1) O(n) 0.04-0.06ms Real-time network security

How DHIF Works

Core Formula: 1. Hash Function: hash(IP) = (octet1 * 256³ + octet2 * 256² + octet3 * 256 + octet4) % TABLE_SIZE 2. Index Calculation: index = hash(IP) % STRIDE_SIZE 3. Lookup: if (hashTable[index].ip == targetIP) return AUTHORIZED else return check_collision_chain() Key Features: - O(1) average case lookup time - Collision handling via chaining - Cache-friendly memory access patterns - Minimal memory overhead per IP entry

DHIF Advantages

  • Speed: 30-50x faster than binary search
  • Scalability: Performance remains constant as IP list grows
  • Memory Efficient: Uses hash table compression
  • Real-Time Processing: Sub-millisecond response for DDoS mitigation
  • Rate Limiting Integration: Built-in protection against abuse

Rate Limiting Protection

DHIF includes intelligent rate limiting to prevent algorithmic degradation:

  • Limit: 3 authorization attempts per IP within 5 seconds
  • Action: Automatic 30-second block on violation
  • Purpose: Prevents automated abuse and DoS preparation
  • Detection: Tracks timestamp-based patterns per IP
