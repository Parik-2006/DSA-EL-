PROJECT DOCUMENTATION

1. OBJECTIVE:
Demonstrate the efficiency gap between legacy firewalls (Linear O(N)) and modern Trie-based defenses (O(1) / O(k)).

2. ALGORITHMS USED:
- Linear Array: Iterates every IP. Slows down as list grows.
- Binary Trie: Bitwise tree structure. Fast O(32).
- Stride-4 Engine: Processes 4 bits at a time. Ultra-fast O(8).

3. FEATURES:
- Real-time DDoS Simulation.
- Rate Limiting logic (>5 req/10s).
- CIDR Subnet Blocking (e.g. 10.0.0.0/8).
